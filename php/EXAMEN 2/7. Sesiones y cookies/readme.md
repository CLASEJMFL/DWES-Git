# 🛒 Práctica: Tienda Online Sencilla

## 📋 Objetivo
Desarrollar una aplicación web de comercio electrónico básica que cuente con un **catálogo de productos** interactivo y un **carrito de la compra** dinámico.

---

## ⚙️ Requisitos Funcionales

### 1. Catálogo de Productos
* **Cantidad:** Debe incluir entre **4 y 5 productos** disponibles.
* **Información del producto:** Cada artículo debe mostrar claramente:
  * 🖼️ Una **imagen** identificativa.
  * 📝 Una **descripción** del producto.
  * 💶 Su **precio**.
* **Acción de compra:** Junto a cada producto debe haber un botón **`Comprar`** que permita añadirlo al carrito.

### 2. Carrito de la Compra
* **Gestión de cantidades:** Si el usuario hace clic en **`Comprar`** sobre un producto que ya se encuentra en el carrito, **no se duplicará la fila**, sino que se incrementará el número de unidades de dicho producto.
* **Eliminación de artículos:** Cada producto listado dentro del carrito debe incluir un botón **`Eliminar`** para que el usuario pueda quitar ese artículo concreto si decide no comprarlo.
